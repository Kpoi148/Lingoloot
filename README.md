# LingoLoot

LingoLoot is a vocabulary-first English learning platform with quizzes, practice modes,
and an admin dashboard. The Next.js app lives in `engquest-nextjs/`.

## Features
- User authentication with profiles.
- Vocabulary topics and curated word lists.
- Quizzes, practice sessions, and progress tracking.
- Story Cloze game mode with AI-assisted generation.
- Admin dashboard for managing content and users.
- Media uploads for richer learning materials.

## Tech Stack
- Next.js 15 (App Router), React 19
- Tailwind CSS
- MongoDB + Mongoose
- NextAuth (Credentials provider)
- Google Generative AI (Gemini)
